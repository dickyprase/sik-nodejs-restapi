
# SIK (Sistem Informasi Karyawan) API with NodeJs+Prisma 




## Installation

Clone my repository, run npm install then copy .env

```bash
  npm install
  cp .env.example .env
```

Edit your .env file then run with :

```bash
  npm run dev
```
## API Reference

#### Get all items

```http
  GET /api/users
```
