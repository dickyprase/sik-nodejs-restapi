
# SIK (Sistem Informasi Karyawan) API with NodeJs+Prisma 




## Installation

Clone my repository, run npm install then copy .env

```bash
  npm install
  cp .env.example .env
```

Edit your .env file then run with :

```bash
  npm run dev
```
## API Reference

#### Get all users

```bash
  GET /api/users
```

#### Get user by id

```bash
  GET /api/user/:id
```

#### ADD user 

```bash
  POST /api/user/
```

#### UPDATE user 

```bash
  PUT /api/user/:id
```

#### DELETE user 

```bash
  DELETE /api/user/:id
```
